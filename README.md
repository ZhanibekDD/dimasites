# Stroydnepr.ru — сайт ГК «ДНЕПР»

Новая статическая версия корпоративного сайта с отдельными SEO-страницами, формой заявки и автоматической публикацией на Timeweb.

## Как устроено принятие изменений

1. Изменения делаются в отдельной ветке и оформляются Pull Request в `main`.
2. GitHub автоматически проверяет структуру и ссылки сайта.
3. После просмотра изменений нажмите **Merge pull request** на GitHub.
4. Принятая версия сразу публикуется в действующий каталог `https://stroydnepr.ru/`.

Отдельный preview-сайт и второй production-сайт не нужны. Основной сайт не меняется до объединения Pull Request.

## Первичная настройка Timeweb

1. В Timeweb откройте **Резервные копии** и создайте копию действующего Stroydnepr.ru. Это единственная обязательная страховка перед первой публикацией.
2. В **Пользователи ПУ/FTP** возьмите данные существующего FTP-пользователя или создайте нового с доступом к каталогу действующего сайта.
3. В **Файловом менеджере** найдите точный путь к каталогу, из которого сейчас открывается `stroydnepr.ru` (обычно это каталог вида `stroydnepr.ru/public_html/`).
4. Добавьте четыре секрета GitHub из раздела ниже.
5. Объедините Pull Request. GitHub сразу заменит файлы в действующем каталоге новой версией.

## GitHub Secrets

Откройте `Settings → Secrets and variables → Actions → New repository secret` и добавьте:

- `TIMEWEB_FTP_SERVER` — FTP-сервер из дашборда Timeweb, без `ftp://`;
- `TIMEWEB_FTP_USERNAME` — логин FTP-пользователя основного сайта;
- `TIMEWEB_FTP_PASSWORD` — пароль FTP-пользователя основного сайта;
- `TIMEWEB_DIR` — путь к каталогу действующего сайта, обязательно с `/` в конце.

Пример пути Timeweb: `stroydnepr.ru/public_html/`. Укажите именно тот путь, который виден в файловом менеджере вашего аккаунта. Не объединяйте Pull Request, пока все четыре секрета не добавлены.

## Перед запуском рекламы и активного SEO

- подтвердить актуальные реквизиты, допуски, список услуг и новые объекты у руководителя;
- подключить Яндекс Метрику, Яндекс Вебмастер и Google Search Console;
- отправить `https://stroydnepr.ru/sitemap.xml` в поисковые системы;
- добавить цели: отправка формы, клик по телефону, клик по e-mail;
- проверить получение писем с формы на `office@stroydnepr.ru`.
