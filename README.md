# Stroydnepr.ru — сайт ГК «ДНЕПР»

Новая статическая версия корпоративного сайта с отдельными SEO-страницами, формой заявки и автоматической публикацией на Timeweb.

## Как устроено принятие изменений

1. Изменения делаются в отдельной ветке и оформляются Pull Request в `main`.
2. GitHub автоматически проверяет структуру и ссылки сайта.
3. После просмотра изменений нажмите **Merge pull request** на GitHub.
4. Timeweb проверяет ветку `main` каждую минуту и публикует принятую версию в `https://stroydnepr.ru/`.

Отдельный preview-сайт и второй production-сайт не нужны. Основной сайт не меняется до объединения Pull Request.

## Первичная настройка Timeweb

1. В Timeweb проверьте наличие автоматической резервной копии действующего Stroydnepr.ru.
2. Включите SSH на дашборде и откройте **SSH-консоль**.
3. Один раз выполните команды:

```bash
git clone --depth 1 --branch main https://github.com/ZhanibekDD/dimasites.git "$HOME/dimasites-deploy"
sh "$HOME/dimasites-deploy/scripts/timeweb_deploy.sh"
```

Скрипт перед первой заменой самостоятельно создаст архив старого сайта в домашней директории аккаунта.

4. В разделе **Сайты → Основной сайт → Настройки версии и кодировки** выберите PHP 8.3 (или 8.2).
5. В **Crontab** добавьте задачу:
   - название: `GitHub Stroydnepr`;
   - интерпретатор: `Сценарий SH`;
   - путь: `/home/c/cg07170/dimasites-deploy/scripts/timeweb_deploy.sh`;
   - периодичность: каждую минуту.

FTP-секреты GitHub не используются: сервер Timeweb не принимает соединения GitHub Actions на порту 21. После проверки первой Git-публикации FTP-пользователя и четыре секрета можно удалить.

## Перед запуском рекламы и активного SEO

- подтвердить актуальные реквизиты, допуски, список услуг и новые объекты у руководителя;
- подключить Яндекс Метрику, Яндекс Вебмастер и Google Search Console;
- отправить `https://stroydnepr.ru/sitemap.xml` в поисковые системы;
- добавить цели: отправка формы, клик по телефону, клик по e-mail;
- проверить получение писем с формы на `office@stroydnepr.ru`.

## Локальная проверка

```bash
python3 scripts/check_site.py
python3 -m http.server 8080 --directory site
```
