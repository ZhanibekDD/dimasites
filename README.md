# Stroydnepr.ru — сайт ГК «ДНЕПР»

Новая статическая версия корпоративного сайта с отдельными SEO-страницами, формой заявки и автоматической публикацией на Timeweb.

## Как устроено принятие изменений

1. Изменения делаются в отдельной ветке и оформляются Pull Request в `main`.
2. Pull Request автоматически публикуется на `https://preview.stroydnepr.ru/`.
3. После проверки нажмите **Merge pull request** на GitHub.
4. Принятая версия автоматически публикуется на `https://stroydnepr.ru/`.

Основной сайт не меняется до объединения Pull Request.

## Первичная настройка Timeweb

1. В Timeweb откройте **Сайты** и создайте отдельный сайт/каталог для новой версии.
2. В **Домены и SSL** создайте поддомен `preview.stroydnepr.ru`, привяжите его к новому сайту и выпустите SSL-сертификат.
3. В **Пользователи ПУ/FTP** создайте отдельного FTP-пользователя для каталога предпросмотра.
4. До первой публикации на основной домен создайте резервную копию текущего сайта.
5. Для production используйте отдельного FTP-пользователя, ограниченного каталогом нового сайта.

## GitHub Secrets

Откройте `Settings → Secrets and variables → Actions → New repository secret` и добавьте:

- `TIMEWEB_FTP_SERVER` — FTP-сервер из дашборда Timeweb, без `ftp://`;
- `TIMEWEB_PREVIEW_FTP_USERNAME` — логин FTP-пользователя предпросмотра;
- `TIMEWEB_PREVIEW_FTP_PASSWORD` — пароль FTP-пользователя предпросмотра;
- `TIMEWEB_PREVIEW_DIR` — путь к каталогу предпросмотра, обязательно с `/` в конце;
- `TIMEWEB_PRODUCTION_FTP_USERNAME` — логин FTP-пользователя основного сайта;
- `TIMEWEB_PRODUCTION_FTP_PASSWORD` — пароль FTP-пользователя основного сайта;
- `TIMEWEB_PRODUCTION_DIR` — путь к каталогу основного сайта, обязательно с `/` в конце.

Пример пути Timeweb: `preview.stroydnepr.ru/public_html/`. Укажите именно тот путь, который виден в файловом менеджере вашего аккаунта.

## Перед запуском рекламы и активного SEO

- подтвердить актуальные реквизиты, допуски, список услуг и новые объекты у руководителя;
- подключить Яндекс Метрику, Яндекс Вебмастер и Google Search Console;
- отправить `https://stroydnepr.ru/sitemap.xml` в поисковые системы;
- добавить цели: отправка формы, клик по телефону, клик по e-mail;
- проверить получение писем с формы на `office@stroydnepr.ru`.

## Локальная проверка

python3 scripts/check_site.py
