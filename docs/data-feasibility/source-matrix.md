## Обязательные поля evidence

Каждый факт хранится отдельной версионируемой записью:

```text
evidence_id
entity_type
entity_id
claim_type
claim_value
source_name
source_url
source_record_id
retrieved_at
valid_at
confidence: A | B | C | D
evidence_excerpt
content_hash
version
review_status
reviewed_by
reviewed_at
```

## Публичные правила

1. Публично показывать утверждение можно только при `confidence=A` или при отдельно одобренном типе `B`.
2. Результат ниже порога маркируется как сигнал или гипотеза и не индексируется.
3. Ответ источника `0 записей` отображается как «в подключённом источнике запись не найдена».
4. Недоступность источника не превращается в отрицательный факт.
5. У каждой карточки показываются источник, дата получения и ссылка на первоисточник.
6. Изменение факта создаёт новую версию; прежняя остаётся в audit log.

## Следующие проверки Sprint 0

- получить sample payload и условия интеграционного доступа ФНС;
- направить оператору ГИС ЕГРЗ запрос о публичном поисковом API и хранении результатов;
- проверить документацию ЕИС и ограничения автоматизированных запросов;
- запросить у НОСТРОЙ и НОПРИЗ разрешённые способы интеграции;
- определить официальные ИСОГД трёх стартовых регионов;
- утвердить российского оператора хранения документов, сроки retention и процедуру удаления;
- получить юридическое заключение по пользовательским согласиям и обработке документов.
